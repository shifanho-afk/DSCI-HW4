# DSCI 552 Homework 4

This repository contains my solution for Homework 4 of DSCI 552: Machine Learning for Data Science.

## Dataset

The homework uses the Activity Recognition System based on Multisensor Data Fusion (AReM) dataset. The dataset contains seven human activity classes:

- bending1
- bending2
- cycling
- lying
- sitting
- standing
- walking

## Contents

- `notebook/`: Jupyter Notebook containing the complete homework solution
- `data/`: AReM dataset
- `requirements.txt`: Required Python packages

## Methods

The notebook includes:

- Time-domain feature extraction
- Binary logistic regression
- Recursive feature elimination
- L1-penalized logistic regression
- Case-control sampling
- Multiclass logistic regression
- Gaussian Naive Bayes
- Multinomial Naive Bayes
- Confusion matrices and ROC curves

## Installation

Install the required packages using:

python -m pip install -r requirements.txt

## Running the Notebook

Open the Jupyter Notebook in the `notebook` folder and run all cells in order. All dataset paths are relative paths.
